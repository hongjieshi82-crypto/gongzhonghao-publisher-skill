# 强调标记语法

这些标记只加符号、不改文字，由 `engine/wx-layouts.js` 按所选风格的排版主题渲染。没有标记的普通 Markdown 也能排好；标记要克制，全文强调不超过七八处，每段最多一处。

## 行内

| 写法 | 效果 | 注意 |
|---|---|---|
| `**文字**` | 本主题的「重点」样式（加粗 + 主题色） | 最常用；一句里只标关键词 |
| `==文字==` | 荧光笔底色 | 标一句结论 |
| `{{文字}}` | 手绘圈注（椭圆圈） | 只放 2–8 个字 |
| `++文字++` | 波浪下划线 | 提示容易忽略的点 |
| `*文字*` | 斜体 | 少用 |
| `` `代码` `` | 行内代码 | 产品名、命令 |

标记只作用在正文文字上，不会进图片地址或链接。

## 段落和块

| 写法 | 效果 |
|---|---|
| 第一个 `## 小标题` 之前的第一段 | 导语（lede） |
| 整段都是 `**…**` 的单独一段 | 金句放大 |
| `> 引用文字 —— 出处` | 引文卡片，`——` 后面是出处（30 字以内） |
| `> 【重点】文字` 或 `> [!重点] 文字` | 带标签的提示框，标签 1–8 字（如 重点、提示、注意、结论） |
| `> 【数据】3周｜说明；4000+｜说明` | 数字卡：每项“数字｜说明”，项与项之间用 `；` |
| `1. 2. 3.` 有序列表 | 编号要点（每条第一句加强） |
| `- ` 无序列表 | 圆点列表 |
| Markdown 表格 | 主题化表格 |
| `---` | 分隔线 |
| 全文最后一段 | 结尾样式 |
| `![](images/01.png)` 单独一行 | 配图（图下不显示任何说明，`build.js` 会清空 alt） |

## 已知限制

- 引用块里的多行会被合成一行（`md.js` 用空格拼接），所以 `【对比】` 之类需要换行分栏的写法不会变成左右对比卡，而是排成普通提示框。需要对比时用表格。工作台也是同样的行为，本 Skill 没有修改引擎。
- 标题只用 `# 标题`（第一行）和 `## 小标题` / `### 三级标题`；`# 标题` 只用于预览，不进复制内容。
- 不要写 HTML 标签、`<style>` 或脚本；公众号会过滤掉。

## front matter（可选）

```markdown
---
摘要: 一两句话，填进公众号摘要栏
---
# 文章标题
```

front matter 和 HTML 注释不会进入正文。
